# split_pdf

Интерактивный консольный скрипт для разделения PDF-файла на части. Никаких аргументов командной строки: скрипт сам находит PDF рядом с собой и задаёт вопросы.

## Возможности

- **Автопоиск PDF** — находит все `.pdf` в папке, где лежит скрипт (или исполняемый файл), и предлагает выбрать нужный. Если файл один, выбирает его сам.
- **Три режима деления:**
  1. **Постранично** — каждая страница в отдельный файл.
  2. **Блоки фиксированного размера** — по `n` страниц в блоке; последний блок может быть короче.
  3. **Блоки по списку длин** — например `3, 7, 2, 2, 4`. Разделители: запятая, пробел или `;`. Если сумма меньше общего числа страниц, остаток добавляется к последнему блоку. Если больше — скрипт попросит повторить ввод.
- **PDF под паролем** — запрашивает пароль (ввод скрыт), 3 попытки.
- **Защита от перезаписи** — если файлы с такими именами уже есть, спрашивает подтверждение.
- **Валидация ввода** — 3 попытки на числовые вопросы, понятные сообщения об ошибках.
- **Аккуратные имена** — номера с ведущими нулями, чтобы файлы сортировались правильно.

### Куда сохраняется результат

| Режим | Папка | Имя файла |
|---|---|---|
| Постранично | `<имя>_pages/` | `<имя>_page_001.pdf` |
| Блоки (n или список) | `<имя>_blocks/` | `<имя>_block_01_p001-005.pdf` |

Исходный файл не изменяется.

## Запуск из исходников

Требуется Python 3.9+.

```bash
pip install pypdf cryptography
python split_pdf.py
```

> `cryptography` нужен для PDF с AES-шифрованием. Для незащищённых файлов достаточно `pypdf`.

1. Положите `split_pdf.py` и нужные PDF в одну папку.
2. Запустите скрипт и следуйте подсказкам.

Пример сессии:

```
В папке '/home/user/docs' найдены PDF-файлы:
  1. contract.pdf
  2. report.pdf

Какой файл разделить? Номер (1-2): 2
Всего страниц: 23

Выберите тип деления:
  1. постранично
  2. на блоки фиксированного размера n
  3. на блоки по списку длин
Номер (1-3): 3
Введите длины блоков через запятую или пробел (например 3, 7, 2, 2, 4): 5, 10, 8

Создаётся файлов: 3
  report_block_01_p001-005.pdf
  report_block_02_p006-015.pdf
  report_block_03_p016-023.pdf

Готово. Создано: 3, пропущено: 0.
```

## Сборка исполняемых файлов

Скрипт можно упаковать в самостоятельную программу, чтобы пользователям не нужен был Python. Для этого используется [PyInstaller](https://pyinstaller.org). Собирать нужно **на той же ОС**, для которой делается файл: `.exe` — на Windows, `.app` — на macOS (кросс-компиляции нет).

### Обязательная подготовка кода перед сборкой

В исходном виде скрипт определяет рабочую папку через `__file__`. В собранной программе это работает неправильно (PyInstaller распаковывает файлы во временную папку, а у `.app` исполняемый файл лежит внутри пакета), поэтому скрипт не найдёт ваши PDF. Замените строку

```python
SCRIPT_DIR = Path(__file__).resolve().parent
```

на:

```python
def get_base_dir() -> Path:
    """Папка, где лежит скрипт / .exe / .app (а не временная папка PyInstaller)."""
    if getattr(sys, "frozen", False):
        exe = Path(sys.executable).resolve()
        for parent in exe.parents:          # macOS: X.app/Contents/MacOS/X
            if parent.suffix == ".app":
                return parent.parent        # папка, в которой лежит .app
        return exe.parent                   # Windows / обычный бинарник
    return Path(__file__).resolve().parent


SCRIPT_DIR = get_base_dir()
```

Чтобы окно консоли на Windows не закрывалось мгновенно после завершения, замените блок `if __name__ == "__main__":` на:

```python
if __name__ == "__main__":
    try:
        main()
    except KeyboardInterrupt:
        print("\nПрервано.")
    except SystemExit:
        pass
    finally:
        if getattr(sys, "frozen", False):
            input("\nНажмите Enter для выхода...")
```

(Код возврата при `sys.exit(1)` в этой версии не сохраняется — для интерактивной программы это не важно.)

## Вариант 1. Windows (`.exe`)

### Сборка

1. Установите Python 3.9+ с [python.org](https://www.python.org/downloads/) (отметьте **Add Python to PATH**).
2. Откройте PowerShell или cmd в папке со скриптом и выполните:

   ```powershell
   pip install pyinstaller pypdf cryptography
   pyinstaller --onefile --console --name split_pdf split_pdf.py
   ```

3. Готовый файл появится в `dist\split_pdf.exe`.

### Использование

1. Скопируйте `split_pdf.exe` в папку с PDF-файлами, которые нужно разделить.
2. Дважды щёлкните по `split_pdf.exe` — откроется окно консоли.
3. Следуйте подсказкам: выберите файл, тип деления, введите параметры.
4. Результат появится в подпапке рядом с `.exe` (`<имя>_pages` или `<имя>_blocks`).
5. Когда появится «Нажмите Enter для выхода...», нажмите Enter.

### Возможные проблемы

- **SmartScreen: «Windows защитила ваш компьютер».** Файл не подписан. Нажмите **Подробнее → Выполнить в любом случае**.
- **Антивирус ругается.** Для программ, собранных PyInstaller, это частая ложная тревога. Соберите `.exe` сами из исходников или добавьте файл в исключения.
- **Первый запуск медленный.** В режиме `--onefile` программа каждый раз распаковывается во временную папку — это нормально.
- **Папка в защищённом месте** (`C:\Program Files`, корень диска): может не хватить прав на запись. Используйте папку в «Документах» или на рабочем столе.

## Вариант 2. macOS (`.app`)

Скрипт интерактивный: ему нужен терминал для ввода. Обычное приложение PyInstaller (`--windowed`) запускается без терминала и работать не будет, поэтому `.app` делается как небольшая «обёртка», которая открывает Terminal и запускает внутри собранную программу.

### Сборка

1. Установите Python 3.9+ (например, `brew install python`).
2. В Terminal перейдите в папку со скриптом и соберите программу:

   ```bash
   pip3 install pyinstaller pypdf cryptography
   pyinstaller --onefile --console --name split_pdf split_pdf.py
   ```

   Получится исполняемый файл `dist/split_pdf`.

3. Создайте структуру `.app` и скопируйте в неё программу:

   ```bash
   APP="SplitPDF.app"
   mkdir -p "$APP/Contents/MacOS" "$APP/Contents/Resources"
   cp dist/split_pdf "$APP/Contents/Resources/split_pdf"
   chmod +x "$APP/Contents/Resources/split_pdf"
   ```

4. Создайте файл запуска `SplitPDF.app/Contents/MacOS/launcher`:

   ```bash
   cat > "$APP/Contents/MacOS/launcher" <<'EOF'
   #!/bin/bash
   DIR="$(cd "$(dirname "$0")" && pwd)"
   BIN="$DIR/../Resources/split_pdf"
   osascript <<OSA
   tell application "Terminal"
       activate
       do script "'$BIN'; exit"
   end tell
   OSA
   EOF
   chmod +x "$APP/Contents/MacOS/launcher"
   ```

5. Создайте `SplitPDF.app/Contents/Info.plist`:

   ```bash
   cat > "$APP/Contents/Info.plist" <<'EOF'
   <?xml version="1.0" encoding="UTF-8"?>
   <!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN"
    "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
   <plist version="1.0">
   <dict>
       <key>CFBundleName</key><string>SplitPDF</string>
       <key>CFBundleIdentifier</key><string>local.splitpdf</string>
       <key>CFBundleExecutable</key><string>launcher</string>
       <key>CFBundlePackageType</key><string>APPL</string>
       <key>CFBundleVersion</key><string>1.0</string>
   </dict>
   </plist>
   EOF
   ```

   > Если при вставке в Terminal отступы heredoc мешают, сохраните содержимое в файлы вручную без начальных пробелов.

6. Снимите карантинный флаг (нужно, если приложение будет передаваться другим людям):

   ```bash
   xattr -cr SplitPDF.app
   ```

### Использование

1. Положите `SplitPDF.app` в папку с PDF-файлами (**рядом** с ними, а не в «Программы»).
2. Запустите двойным щелчком — откроется окно Terminal.
3. Следуйте подсказкам: выберите файл, тип деления, введите параметры.
4. Результат появится в подпапке рядом с `SplitPDF.app` (`<имя>_pages` или `<имя>_blocks`).
5. Окно Terminal закроется автоматически после завершения (если нужно увидеть вывод, уберите `; exit` в `launcher`).

### Возможные проблемы

- **«Приложение повреждено» / «невозможно проверить разработчика».** Приложение не подписано. Нажмите правой кнопкой по `SplitPDF.app` → **Открыть** → **Открыть**. Или выполните `xattr -cr SplitPDF.app`.
- **Запрос доступа к папке.** При первом запуске macOS может спросить разрешение на доступ к «Документам», «Рабочему столу» или «Загрузкам» — разрешите.
- **Архитектура.** Сборка работает на том типе процессора, на котором создана (Apple Silicon или Intel). Для другой архитектуры соберите заново на соответствующем Mac.
- **Запуск без обёртки.** Можно просто использовать `dist/split_pdf` из Terminal: положите его рядом с PDF и выполните `./split_pdf`.
